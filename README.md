# ZONIX DIGITAL — Marketplace

Современный интернет-магазин цифровой техники и брендовой одежды, разработанный на фреймворке Django с использованием Session-based архитектуры для управления корзиной покупок.

## Ключевой функционал

- **Умная корзина покупок (Session-based):** Архитектура корзины учитывает специфику разных категорий товаров. Реализована динамическая генерация ключей: одежда группируется по ID и размеру (`ID_размер`), а цифровая техника — строго по уникальному `ID`.
- **Каталог товаров (`shop`):** Динамический вывод продуктов, гибкая система фильтрации по категориям, контроль остатков товаров на складе (`stock`) при добавлении в корзину.
- **Модуль заказов (`orders`):** Оформление покупок с фиксацией цен на момент заказа, валидацией данных и автоматической очисткой сессии корзины.
- **Точные финансовые расчеты:** Все операции с ценами и стоимостью позиций реализованы с использованием модуля `Decimal`, что исключает погрешности округления типа `float`.
- **Безопасность:** Защита всех форм изменений данных (добавление, обновление количества, удаление) с помощью `csrf_token` и ограничение доступа для неавторизованных пользователей (`@login_required`).

## Стек технологий

- **Backend:** Python 3.x, Django 4.2+ (Django ORM, Views, Templates)
- **Frontend:** HTML5, CSS3, Bootstrap 5 (Адаптивная верстка)
- **Database:** SQLite (разработка) / готовность к миграции на PostgreSQL
- **Окружение:** Linux (Debian/Ubuntu), Git

## Установка и развертывание

### 1. Клонирование репозитория
```bash
git clone [https://github.com/Montana-gg/zonix_marketplace.git](https://github.com/Montana-gg/zonix_marketplace.git)
cd zonix_project
```
### 2. Настройка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций и запуск
```bash
python manage.py migrate
python manage.py runserver
```

После запуска проект будет доступен в браузере по адресу: http://127.0.0.1:8000/


### Структура проекта

    shop/ — каталог товаров, модели категорий и продуктов, логика отображения.

    cart/ — кастомный модуль корзины, обработка сессий пользователей, управление CRUD операциями для позиций.

    orders/ — сбор данных покупателя, генерация и сохранение заказов в БД.
